# Cage

> **POC.** Early / unstable. Developed and tested on **macOS** only (Tart + softnet). Other hosts are not supported yet.

Host CLI that runs agent workloads in a sandboxed runtimes with config-driven filesystem, secrets, and fail-closed egress.
